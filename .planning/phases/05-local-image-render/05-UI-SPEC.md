## Component Inventory

New components introduced in Phase 5. All live in `packages/workspace/src/`.

### RenderPanel

Inline panel displayed below the FormatSwitcher on the Editor screen. Never a modal, never overlaps the canvas.

**States:**

| State | Visual |
|-------|--------|
| Idle (pre-render) | Render button only; no status rows visible |
| Flushing save | Render button disabled, label: "Saving…" |
| Rendering (per-format) | Three format rows with spinner / pending / complete indicators; Render button hidden |
| Complete | Three format rows all showing complete; preview images replace canvas preview; action row (Copy caption, Download per-format, Open folder) visible |
| Partial failure | Completed formats show complete + actions; failed format shows error row with message |
| Full failure | All three rows show error state; Render button re-enabled with label: "Retry render" |

**Layout:** Stacked vertically. Render button full-width. Format rows are a 3-item list: `[status indicator] [format label] [download link when done]`. Action row is a horizontal flex of three buttons with 8px gap.

### FormatStatusRow

One row per format (Landscape, Square, Portrait). Shows:
- Idle: muted dot + label in `--workspace-muted`
- Pending: spinning indicator (CSS animation, no external library) + label in `--workspace-ink`
- Complete: lime-filled checkmark + label in `--workspace-forest` + "Download" anchor link (right-aligned)
- Failed: red X indicator + label in `--workspace-forest` + inline error message in red-500/10 background

### RenderedPreview

After render completes, the `<TemplatePreview>` component is replaced by an `<img>` tag pointing at `/output/<id>/<format>.jpg`. Displayed in the same canvas wrapper (existing `rounded-[8px] border border-[var(--workspace-border)] bg-white overflow-hidden` container). No lightbox, no zoom — simple static image preview.

The FormatSwitcher still operates; switching formats swaps which rendered JPEG is shown.

### ActionRow

Horizontal flex row with 8px gap. Three actions:

1. **Copy caption** — button, full text label "Copy caption", icon optional. On success: label changes to "Copied!" for 2s then reverts. Uses `navigator.clipboard.writeText()`.
2. **Download** — `<a download>` anchor styled as button, label "Download [format]" (e.g. "Download landscape"). Points at `/output/<id>/landscape.jpg`.
3. **Open folder** — button, label "Open folder". `POST /api/local/reveal` on the CLI server; triggers OS folder reveal.

## Interaction Contracts

### Render Button

- **Idle:** `bg-[var(--workspace-lime)] text-[var(--workspace-forest)] font-semibold` — full-width, min-height 44px.
- **Disabled (flushing):** `opacity-50 cursor-not-allowed`, label "Saving…"
- **Active render in progress:** button hidden; replaced by format status rows.
- **Retry state:** button re-appears with label "Retry render", same styling.
- **Hover:** slight opacity reduction (`hover:opacity-90`), consistent with existing Workspace button hover patterns.

### Polling

SPA polls `/api/local/render/:id/status` every 1000ms after triggering render. On each response, update per-format state. Stop polling when all formats reach `done` or `failed` (or a mix). No timeout UI required — render-core failures propagate to the status endpoint.

### Error Display

Errors appear inline in the `FormatStatusRow` for the affected format. Error text is the `message` from the CLI status response. No toast, no modal. If all three fail, a single summary line may appear above the format rows: "Render failed. Check the terminal for details."

## Accessibility

- Render button: min 44x44px touch target.
- Action buttons (Copy caption, Download, Open folder): min 44px height.
- Spinning render indicator: `role="status"` + `aria-label="Rendering [format]"`.
- Download anchors: `aria-label="Download [format] image"`.
- Open folder button: `aria-label="Open output folder in file manager"`.
- All status changes announced via a live region: `aria-live="polite"` on the RenderPanel container.
- `aria-disabled="true"` on Render button when flushing/saving.
