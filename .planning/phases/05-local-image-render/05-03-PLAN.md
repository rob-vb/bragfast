    EXPORTED TYPES:

    RenderPhase type: "idle" | "flushing" | "rendering" | "done" | "failed-all" | "partial"
    — "idle": no render in progress
    — "flushing": flush save called, waiting for save to land
    — "rendering": job submitted, polling in progress
    — "done": all three formats are in "done" state
    — "partial": at least one format done and at least one failed
    — "failed-all": all three formats are in "failed" state

    UseRenderArgs interface:
    - flush: () =&gt; Promise&lt;string | null&gt;   // from useAutoSave

    UseRenderResult interface:
    - renderPhase: RenderPhase
    - formats: Record&lt;"landscape" | "square" | "portrait", FormatRenderState&gt;
    - jobId: string | null
    - trigger: () =&gt; Promise&lt;void&gt;   // entry point: flush → POST → start poll

    HOOK IMPLEMENTATION:

    State:
    - renderPhase: useState&lt;RenderPhase&gt;("idle")
    - formats: useState&lt;Record&lt;"landscape"|"square"|"portrait", FormatRenderState&gt;&gt; — initial value: { landscape: { phase: "idle" }, square: { phase: "idle" }, portrait: { phase: "idle" } }
    - jobId: useState&lt;string | null&gt;(null)

    trigger() function:
    1. If renderPhase is "flushing" or "rendering", return immediately (guard against double-click)
    2. Set renderPhase to "flushing"; set all formats to { phase: "pending" }
    3. const draftId = await flush() — from UseRenderArgs.flush
    4. If draftId is null, set renderPhase to "failed-all"; set all formats to { phase: "failed", error: "Save failed before render" }; return
    5. Set all formats to { phase: "pending" }
    6. const job = await triggerRender(draftId)
    7. Set jobId to job.id; set renderPhase to "rendering"
    8. Polling starts via the useEffect below

    Polling useEffect (depends on [jobId]):
    - If jobId is null, do nothing
    - Set up window.setInterval(pollTick, 1000)
    - pollTick: call pollRenderStatus(jobId).then(resp => { ... }).catch(err => { /* log, mark all formats failed, clear interval */ })
    - In the .then: update formats state from resp.formats; compute new renderPhase:
      - all done → "done"; clear interval; set renderPhase "done"
      - all failed → "failed-all"; clear interval; set renderPhase "failed-all"
      - mix of done + failed (no pending remaining) → "partial"; clear interval; set renderPhase "partial"
      - otherwise: keep polling (interval continues)
    - Cleanup: clear interval on unmount or when jobId changes

    Terminal state check helper function isTerminal(formats): boolean — returns true if every format is "done" or "failed" (no "idle" or "pending" remaining)

    IMPORTANT: trigger() must be a stable callback — use useCallback with [flush] as the dependency array to avoid stale closures in the component.

    Export: useRender(args: UseRenderArgs): UseRenderResult
