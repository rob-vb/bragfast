# Plan 02-01 — Convex Device-Code Lifecycle

## Objective

Add the backend state machine for device-flow login.

## Tasks

1. Add `deviceCodes` table to `convex/schema.ts` using the shape in `02-PATTERNS.md`.
2. Implement `convex/deviceCodes.ts`.
3. If needed, add an internal helper to `convex/apiKeys.ts` so `exchangeToken` can mint a key without duplicating key generation.
4. Add `convex/__tests__/deviceCodes.test.ts`.
5. Run:

```bash
npx convex codegen --typecheck=disable
npx vitest run convex/__tests__/deviceCodes.test.ts
```

## Acceptance

- Tests cover pending, approved, denied, expired, consumed, and auth-gated approve/deny.
- Approved exchange returns a raw `bf_` API key once.
- Second exchange for the same `device_code` does not return another key.
