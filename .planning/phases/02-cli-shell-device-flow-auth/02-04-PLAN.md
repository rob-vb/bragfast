# Plan 02-04 — CLI Package

## Objective

Create the npm workspace CLI package with `brag`, `brag login`, and `brag logout`.

## Tasks

1. Add `packages/cli` package using ESM `tsup` build.
2. Add dependencies: `commander`, `open`, `ora`.
3. Implement credential helpers with `BRAG_HOME` test override and default `~/.brag`.
4. Implement backend HTTP helpers with `BRAG_API_URL` override.
5. Implement device-flow login: issue code, print code+URL, open browser, poll token endpoint every `interval`.
6. Add Vitest unit tests for credential modes and auth polling behavior.
7. Add root script if useful: `cli:build`.

## Acceptance

- `npm run build --workspace=packages/cli` passes.
- `npx vitest run packages/cli` passes.
- `node packages/cli/dist/index.js --help` shows `brag` command help.
- `node packages/cli/dist/index.js logout` removes a temp credential file.
