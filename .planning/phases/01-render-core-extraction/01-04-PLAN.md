        Initialize result: ImageRenderResult = { formats: {} }.

            seenLayouts = new Set<string>().
            fonts array starts empty.

              layout = slide.templateConfig.formats[format as FormatKey] ?? .formats.landscape
              layoutKey = JSON.stringify(layout.objects.map(o => o.id)).
              If seenLayouts.has(layoutKey) skip. Else add and loadFontsForObjects(layout.objects),
              spread into fonts.
            If req.brand.font_family: loadFontsForFamily(req.brand.font_family), spread into fonts.

          Per-slide loop: for each slide in formatEntry.slides:
            Normalize objectData entries: for each value in slide.objectData,

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller-provided base64 → normalizeDataUri → sharp | Base64 media bytes (objectData.imageBase64) flow through Sharp's PNG normalization |
| Caller-provided objectData → injectStaticImages | srcMap values injected into objectData slots |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of Service | normalizeDataUri — large base64 input | accept | Base64 decoded by Sharp; Sharp has internal size limits; caller is the Next.js app route or CLI (both trusted); no untrusted network input in this package |
| T-04-02 | Tampering | injectStaticImages — srcMap injection | accept | srcMap is populated by the app-side resolver layer (prefetchStaticImages) with already-fetched base64 data; not attacker-controlled in the current trust model (server-side caller) |
| T-04-03 | Information Disclosure | JPEG output buffer | accept | Buffers returned to caller; render-core never writes to disk or network; no information disclosure risk in the package itself |
| T-04-SC | Tampering | npm/pip installs | accept | No new packages installed in this plan |
</threat_model>
