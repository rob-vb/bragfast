<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller-provided remotionEntryPoint → @remotion/bundler | Absolute path string used as Webpack entry point |
| @remotion/renderer → os.tmpdir() | MP4 file written to and read from system temp directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | remotionEntryPoint path parameter | accept | In Phase 1 the only callers are the app route and the prove-video.mjs script; both are trusted (not user-controlled at this layer). Phase 2+ CLI caller will validate the path before passing. |
| T-05-02 | Denial of Service | @remotion/renderer Chromium download | accept | First-run only; Chromium download is ~170MB; cached in ~/.remotion/ on subsequent calls; ensureBrowser() is Remotion's own managed binary; no attacker control over binary selection |
| T-05-03 | Tampering | os.tmpdir() MP4 write + read | accept | tmpFile name includes crypto.randomUUID() — no race condition between concurrent renders; file is unlinked immediately after read; tmp directory is process-owned in standard OS configurations |
| T-05-04 | Information Disclosure | inputProps forwarded to Remotion bundler | accept | inputProps come from caller (app route or CLI); render-core does not log or persist them beyond the render call |
| T-05-SC | Tampering | npm/pip installs | accept | No new packages installed in this plan |
</threat_model>
