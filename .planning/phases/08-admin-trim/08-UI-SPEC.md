## Spacing Scale

Tailwind default 4px scale. No custom spacing tokens defined in the project.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, button internal gaps |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, card body padding (p-5/p-6) |
| xl | 32px | Layout gaps, page section breaks |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets: minimum 44x44px for all interactive elements (accessibility rule, DESIGN.md)
- NES card body: p-5 or p-6 (20px or 24px) per component pattern
- PixelEmptyState: p-8 (32px) internal padding

|------|------|------|--------|-------------|--------|
| Body | Geist Sans | 14px | 400 (regular) | 1.5 | DESIGN.md |
| Label / small UI | Geist Sans | 12px | 400 (regular) | 1.4 | DESIGN.md minimum |

Rules:
- Press Start 2P minimum: 10px. Never below 10px for readable text. Sub-10px only for decorative/unread elements.
- Geist Sans minimum: 12px for readable UI text.
- Two weights in use: regular (400) for both fonts. Press Start 2P has only one weight.

## Color

| Role | Token | Value | Usage | Source |
|------|-------|-------|-------|--------|
| Dominant (60%) | `--color-surface` / `bg-surface` | `#FFF8F0` | Page backgrounds, sidebar, card surfaces | DESIGN.md |
| Secondary (30%) | `white` / `bg-white` | `#FFFFFF` | Card bodies, inputs, modal panels | DESIGN.md |
| Brand / text | `--color-brand` / `text-brand` | `#4A3326` | Primary text, borders, shadows, header bars | DESIGN.md |
| Accent (10%) | `--color-gold` / `bg-gold` | `#F8AF3C` | **Reserved for:** primary CTA buttons, active nav states, focus outlines, NES card header bar on hover | DESIGN.md |
| Destructive | `--destructive` | `oklch(0.577 0.245 27.325)` | Delete confirmations, danger-zone actions only | globals.css |

Accent reserved for (explicit list — never used for general decoration):
1. Primary CTA button background (`PixelButton` primary variant)
2. Active/selected nav state indicator
3. Focus ring: `outline-2 outline-offset-2 outline-gold`
4. NES card header bar hover state
5. Table header row background tint (`bg-gold/20`)

Gold is NOT used for: body text, borders, secondary buttons, status badges.

Shadow: hard pixel-art offset shadow in `--color-brand` at all scales. No soft drop shadows.
Border radius: 0 for pixel-art elements (NES cards, PixelButton, PixelTable). Default shadcn radius (0.625rem) for form inputs only.

## Surfaces Changed This Phase

### Admin Sidebar (modify)

Remove nav links: Kitchen, Drafts, Briefing, Goals, Activity, Settings (Sous-Chef)
Add nav link: Integrations → `/admin/integrations`
Keep: Templates, Brands, History (gallery), API Keys, Account

Nav link visual pattern: Geist Sans 14px, brand color, gold left-border on active state. No change to existing pattern.

### /admin Dashboard (slim — D-06)

Strip: Sous-Chef activity widget
Keep: stats row (PixelCard × N), recent Creations list
Layout: two-column at lg breakpoint (stats row full-width top, recent Creations below).

**Visual focal point:** The stats row is the primary focal point of the /admin landing screen — it is full-width, sits at the top of the content area, and receives the first visual weight. The recent Creations list is the secondary element below it. Exact number of stat cards and widget layout within the stats row is at implementer discretion per Claude's Discretion.

### Gallery / History (read-only — D-13/D-14)

Remove: `SocialCopySection` inline editor (lines 79-203 of history-table.tsx)
Keep: thumbnail, status badge (PixelBadge), download button, JSON viewer
Status set: rendered | scheduled | pending | failed. No `published` badge.
Gallery is display-only — no editing affordances remain.

### /admin/integrations (new page — D-02)

NES card layout. Sections: Buffer connection (OAuth key entry + validate + channels); future provider slots (empty state shown for unconnected providers).
Same connection flow as previously in Sous-Chef settings, new URL/page.

### Default/Custom Toggle in Workspace Picker (D-05)

Toggle button group: "Default" | "Custom"
Default: shows 5 built-in templates (existing)
Custom: shows user's admin-authored templates fetched from `/api/v1/templates`
Empty state for Custom when no templates exist: see Copywriting section.
Toggle visual: PixelButton ghost variant pair, active arm gets bg-gold/primary treatment.

### Account / Billing (D-09..D-12)

Remove: credit bar, credit display, multi-tier upgrade page
Keep: subscription status (subscribed / trial / expired), Manage Billing button, subscribe CTA
Trial indicator: show days remaining during trial (e.g. "12 days left in trial").
Expired trial: surface subscribe prompt in-page (upsell modal pattern or inline banner).

### Subscribe Prompt on 402 in Workspace/CLI (D-11)

Pattern: NES card modal overlay in the Workspace. Header: "▸ Trial Ended". Body explains local render still works; backend features (scheduling, sync) require subscription. Primary CTA: "Subscribe Now". Secondary: "Dismiss" (dismisses modal, CLI continues working locally).
Copy is at implementer discretion per Claude's Discretion (see Copywriting section for directional copy).

## Copywriting Contract

All copy uses the brag.fast diner/NES voice: direct, no AI slop, honest, developer-friendly.

| Element | Copy | Source |
|---------|------|--------|
| Primary CTA (subscribe from account) | Subscribe Now | Default |
| Primary CTA (connect Buffer) | Connect Buffer | Default |
| Primary CTA (API key generation) | Generate Key | Default (existing) |
| Primary CTA (template creation) | New Template | Default (existing) |
| Gallery empty state heading | No creations yet | Default |
| Gallery empty state body | Render something from the Workspace and it'll show up here. | Default |
| Custom templates empty state heading | No custom templates | Default |
| Custom templates empty state body | Build a template in the admin, then it'll appear here. | Default |
| Integrations page — Buffer not connected heading | Buffer not connected | Default |
| Integrations page — Buffer not connected body | Connect your Buffer account to schedule posts directly from the Workspace. | Default |
| Trial active banner | {N} days left in your trial | Default |
| Trial expired in-app prompt heading | Trial ended | Default |
| Trial expired in-app prompt body | Scheduling and sync require a subscription. Local render keeps working. | Default |
| 402 subscribe CTA in Workspace | Subscribe Now | Default |
| Error state (generic) | Something went wrong. Try again or reload the page. | Default |
| Delete API key confirmation | Delete key "{name}"? This can't be undone. | Default (existing pattern) |
| Disconnect Buffer confirmation | Disconnect Buffer? Scheduled posts already sent won't be affected. | Default |

Destructive actions in this phase:
1. Delete API key — confirmation dialog (AlertDialog): "Delete key?" + key name. Confirm button: "Delete Key" (destructive red). Dismiss: "Keep Key".
2. Disconnect Buffer — confirmation dialog: "Disconnect Buffer?" with consequence note. Confirm: "Disconnect" (destructive). Dismiss: "Stay Connected".
3. Delete template — confirmation dialog: "Delete template?" Confirm: "Delete" (destructive). Dismiss: "Keep Template".

All destructive confirmations use the existing `alert-dialog.tsx` shadcn component. Confirm button uses `PixelButton` danger variant (`bg-red-500 text-white`). Dismiss button uses ghost variant.
