<objective>
Add the CLI-local media upload and static serving capability required by Workspace visual/video slot filling.

The browser posts files to `POST /api/local/media`; the CLI writes them to a local cache and returns a URL under `/media/...`. This route is local-only and must be mounted before the authenticated backend proxy.
</objective>
