# Phase 4 - UI Design Contract

> Visual and interaction contract for Workspace Editor + Slot Filling. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

Phase 4 turns the local Workspace shell into a single-screen editor. The first screen is the Workspace home: recent drafts on the left and the 5 built-in templates in a thumbnail grid on the right. Selecting a template or reopening a draft moves into the editor: live canvas preview and slot panel stay visible together, with format tabs directly above the canvas.

Out of scope for UI: render progress, output file previews, scheduling controls, carousel controls, AI-assisted fill, and template authoring.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none for `packages/workspace`; root app has shadcn but this phase must not add shadcn to the Workspace package |
| Preset | not applicable |
| Component library | none; workspace-native React components using Tailwind v4 utilities after adding `tailwindcss` + `@tailwindcss/vite` |
| Icon library | none required for MVP; use text labels for primary commands and native input affordances |
| Font | `Inter` for body/UI, `Sora` for compact headings and key labels, `Geist Mono` only for technical values |

Design language: pivot away from the legacy NES-retro system for the Workspace. Use the attached brand-kit direction: premium, clean SaaS/product-tool surfaces with generous whitespace, thin dividers, subtle borders, deep forest green brand anchors, off-white backgrounds, muted sage secondary elements, charcoal text, and sparing soft-lime accents.

Do not use pixel-art borders, hard offset shadows, Press Start 2P, chunky retro buttons, decorative gradients, or marketing-page composition. This is an editor surface, not a landing page.

---

## Layout Contract

| Screen | Contract |
|--------|----------|
| Workspace home | Full-height app shell with max-width content. Recent drafts and template picker are visible on desktop in two columns; on mobile, recent drafts appear above templates. |
| Editor | Desktop uses a two-column layout: preview column left, slot panel right. Mobile stacks preview above slot panel. |
| Preview column | The live canvas is the visual anchor. Format switcher sits immediately above it. Saved state sits in the same header row, right-aligned. |
| Slot panel | Text slots first, visual/logo slots second, caption textarea last. Caption is visually separated because it is post copy, not rendered canvas text. |
| Recent drafts | Thumbnail, template/name, edited time, and reopen action. Empty state reserves the area; it does not collapse the screen. |
| Template grid | 5 built-in template thumbnails rendered with `TemplatePreview`, each preserving aspect ratio and using the sample/brand preview data. |

Primary focal point: the live canvas preview. Secondary focal point: the slot panel's next editable field. The template grid and recent drafts are decision surfaces; they should be calm, scannable, and stable.

Visual hierarchy:
- Level 1: live preview canvas or template thumbnail.
- Level 2: active format tab, primary template/reopen action, filled media previews.
- Level 3: field labels, saved state, edited time, validation messages.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, checkbox gaps, tiny status spacing |
| sm | 8px | Field internals, thumbnail captions, inline controls |
| md | 16px | Default panel padding, form row spacing |
| lg | 24px | Editor column gap, panel section spacing |
| xl | 32px | Home grid gap, app shell padding on desktop |
| 2xl | 48px | Major separation between home sections on mobile |
| 3xl | 64px | Reserved for page-level breathing room only; avoid inside editor panels |

Exceptions: minimum interactive target height may be 44px for upload zones and primary buttons; this preserves accessibility while staying aligned to the 4px grid.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 600 | 1.35 |
| Body | 14px | 400 | 1.5 |
| Heading | 18px | 600 | 1.3 |
| Display | 24px | 600 | 1.25 |

Rules:
- Use only these four sizes in Workspace UI. Template canvas typography is governed by template config and is exempt.
- Use only weights 400 and 600 in Workspace UI.
- `Sora` is used for headings, selected template titles, and compact section labels. Labels may use uppercase with 0.08em letter spacing.
- Do not use `Press Start 2P` in the Workspace editor.
- Use `Geist Mono` for media ids, repo metadata, draft ids, or file-like values only.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F7F6F2` | App background, home surface, empty state regions |
| Secondary (30%) | `#FFFFFF` | Editor panels, template tiles, recent draft rows, form controls |
| Accent (10%) | `#87FF5C` | Primary CTA highlight, active format underline, selected template indicator, saved success dot |
| Brand / Anchor | `#1F3D3A` | Primary buttons, logo/brand marks, selected navigation, important headings |
| Muted Sage | `#6F8F88` | Secondary badges, subtle data accents, quiet selected surfaces |
| Ink / Text | `#1A1A1A` | Primary text, high-emphasis labels |
| Border | `rgba(26, 26, 26, 0.12)` | Dividers, panel outlines, form controls |
| Muted | `rgba(26, 26, 26, 0.62)` | Secondary copy, helper text, timestamps |
| Destructive | `#DC2626` | Clear media, unsupported file type, failed upload, destructive confirmation text |

Accent reserved for: primary CTA highlight, active format underline, selected template indicator, focus-visible ring, saved success dot, checked brand color swatch. Do not use soft lime for every hover state or every link.

Brand colors from the selected brand affect the rendered canvas and brand color controls only. They must not recolor the Workspace chrome except for explicit color swatches.

## Component Contracts

| Component | Contract |
|-----------|----------|
| `Home` | Shows recent drafts and template grid. Template browsing alone does not create a draft. |
| `TemplatePreview` | Port Kitchen preview behavior: ResizeObserver scaling, `CanvasRenderer`, browser font injection, fixed aspect-ratio wrapper, no Next.js dependencies. |
| `FormatSwitcher` | Segmented control with `Landscape`, `Square`, `Portrait`; active tab uses deep forest text with a soft-lime underline or quiet filled state; tabs do not resize when switching. |
| `SlotPanel` | Renders fields from the selected template object list. Labels derive from `TemplateObject.name`. Logo slot shows auto-filled brand logo with replace/clear affordance if implemented. |
| `VisualField` | Single drop zone per visual slot. Supports drag-drop and click-to-browse, previews image/video, and provides replace + clear actions. |
| `CaptionField` | Dedicated textarea below rendered slots. Placeholder and label must make clear it is social post copy. |
| `BrandPicker` | Workspace-native select + swatches. Auto-picks first/default brand, applies colors/logo, and supports manual colors without shadcn primitives. |
| `SavedIndicator` | Small text/status indicator: `Unsaved`, `Saving...`, `Saved`, `Save failed`. Does not steal focus from editing. |

Do not nest card-style surfaces inside card-style surfaces. Template tiles and draft rows may be cards; the editor columns are panels. Cards use 8px radius maximum, 1px borders, and no hard drop shadows.

## Interaction States

| Interaction | Required State Contract |
|-------------|-------------------------|
| Template select | Open editor immediately with selected template. Apply first/default brand colors and logo when present. |
| Reopen draft | Load full draft config and render the saved format/content. Do not overwrite media refs or caption. |
| First content edit | Create draft only after text, media, caption, brand/color override, or format/content mutation. Template browsing alone is not content. |
| Auto-save | Debounce 800ms-1000ms after last edit. PATCH sends full config. Indicator changes from `Unsaved` to `Saving...` to `Saved`. |
| Save failure | Keep edits in local state, show `Save failed - retrying on next edit`, and do not clear the dirty state. |
| Unsupported file | Show inline error under the specific slot: `Unsupported file type. Use PNG, JPG, WebP, SVG, MP4, MOV, or WebM.` |
| Media upload | Drop zone enters uploading state and blocks duplicate upload for that slot. Successful image/video preview appears inside the drop zone. |
| Clear media | Use a small destructive text button `Clear media`; no modal needed because the source file remains local and the action only clears the slot reference. |
| Format switch | Switches preview layout only; content remains shared by object id. No draft should be created solely by initial default format selection. |

Accessibility:
- Every input has a visible label.
- Drop zones are also buttons with keyboard activation through the hidden file input.
- Focus-visible outline uses `#87FF5C` and at least 2px width.
- Icon-only controls are not allowed in this phase unless an `aria-label` and tooltip are provided.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Start from template` |
| Recent draft CTA | `Reopen draft` |
| Template tile action | `Use template` |
| Empty state heading | `No drafts yet` |
| Empty state body | `Pick a template to start your first local draft.` |
| Template loading state | `Loading templates...` |
| Draft loading state | `Loading draft...` |
| Save states | `Unsaved`, `Saving...`, `Saved`, `Save failed - retrying on next edit` |
| Caption label | `Post caption` |
| Caption placeholder | `Write the caption that will post with this creation.` |
| Media empty state | `Drop media here or browse files` |
| Media replace copy | `Drop a new file or browse to replace` |
| Error state | `Could not load the Workspace. Check that the local brag server is still running, then refresh.` |
| Unsupported media error | `Unsupported file type. Use PNG, JPG, WebP, SVG, MP4, MOV, or WebM.` |
| Destructive confirmation | `Clear media: remove this file from the slot?` only if implemented as a confirmation; otherwise use direct `Clear media` with immediate undo not required |

Avoid generic labels such as `Submit`, `OK`, `Save`, and `Cancel`. If a dialog needs dismissal, use `Close picker`.

## Implementation Notes For Planner

- Add Tailwind v4 to `packages/workspace` with `@tailwindcss/vite`; define Workspace tokens for `forest`, `offWhite`, `sage`, `charcoal`, `lime`, `border`, and `surface`.
- Do not add shadcn to `packages/workspace`.
- Port `TemplatePreview` and slot-field logic, but remove Next.js-only imports and shadcn dependencies.
- Preserve CLI-local media route copy and errors inside the affected slot, not as global toasts.
- Keep `VideoComponent` preview muted, looping, and autoplaying.
- Use stable dimensions for preview wrappers, format tabs, template tiles, and upload zones so media previews and state text do not resize the layout.
- When porting Kitchen components, translate visual styling to this brand-kit direction instead of carrying forward NES-retro classes, shadows, or typography.
