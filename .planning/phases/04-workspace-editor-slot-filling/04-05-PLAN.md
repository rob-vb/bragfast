  <behavior>
    - typing in a text slot calls onConfigChange with `objectContent[object.id].text`
    - caption textarea writes `config.caption` and is not part of objectContent
    - dropping or browsing an image calls uploadLocalMedia and writes `image_url`
    - dropping or browsing a video calls uploadLocalMedia and writes `video_url`
    - unsupported files show `Unsupported file type. Use PNG, JPG, WebP, SVG, MP4, MOV, or WebM.` under that slot
    - clear media removes image_url/video_url for that slot
  </behavior>
  <action>
    Implement SlotPanel fields derived from the current format's object list, ordered as text slots, visual/logo slots, then caption. Labels derive from `TemplateObject.name`.

    VisualField is a button/drop-zone with a hidden file input. It supports drag-drop and click-to-browse, shows uploading state for the active slot, renders image previews with `<img>`, renders video previews with `<video muted loop autoPlay playsInline>`, supports replace by selecting/dropping a new file, and supports direct `Clear media`.

    Logo slot should show auto-filled brand logo when available and allow clear/replace only if the component implements object-level override; do not require writing logo objectContent for brand auto-fill.
  </action>
  <verify>
    <automated>npx vitest run --config packages/workspace/vitest.config.ts packages/workspace/src/__tests__/editor-flow.test.tsx</automated>
  </verify>

    - VisualField supports drag-drop and browse file paths
    - VisualField previews both image and video media after upload
    - Unsupported media error copy exactly matches UI-SPEC
    - Clear media removes local media refs from DraftObjectContent
  </acceptance_criteria>
