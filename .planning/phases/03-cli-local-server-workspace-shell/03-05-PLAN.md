## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → local node_modules | Package installs from external registry — blocked by legitimacy checkpoint |
| packages/workspace/dist → packages/cli/dist/workspace-dist | Static file copy at build time — no runtime network exposure |
| CLI process SIGINT/SIGTERM → server.close() | Graceful shutdown prevents port leak on Ctrl+C |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-10 | Tampering | npm package installs | mitigate | Blocking human checkpoint (Task 1) gates all installs; all packages [ASSUMED] slopcheck — user verifies npmjs.com maintainer org before approving |
| T-03-11 | Information Disclosure | packages/cli/src/index.ts | mitigate | URL printed to stdout only (not stderr, not logs that might be captured); Bearer token is never in index.ts scope — only inside server.ts/proxy.ts |
| T-03-12 | Denial of Service (port leak) | SIGINT/SIGTERM handlers | mitigate | close() calls server.closeAllConnections() + server.close() before process.exit() to release the port cleanly |
| T-03-SC | Tampering | express, get-port, http-proxy-middleware, cors, vite installs | mitigate | Task 1 checkpoint — blocking before any npm install; auto_advance ignored for legitimacy gates |
</threat_model>
