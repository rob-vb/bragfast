    Export function originLockMiddleware(port: number): RequestHandler[] — implements Pattern 2:
    1. hostGuard: if (host && host !== `127.0.0.1:${port}`) → res.status(401).json({ error: "forbidden" }); return
    2. corsMiddleware: cors({ origin: (incoming, callback) => { if (!incoming || incoming === `http://127.0.0.1:${port}`) callback(null, true); else callback(new Error("CORS: forbidden origin")); }, credentials: false })
    Build cors config AFTER receiving the port value (not at module load time) — per Pitfall 3.

    Internal function getSpaDir(override?: string): string:
    If override provided, return it. Otherwise use fileURLToPath(new URL(".", import.meta.url)) to get the directory of the compiled server.js, then path.join(__dirname_equiv, "workspace-dist"). NEVER use __dirname (ESM — Pitfall 1).

    Internal function buildApp(credentials: Credentials, port: number, spaDir: string): Application:
    1. const app = express()
    2. app.use(...originLockMiddleware(port))
    3. app.use("/api", createBackendProxy(credentials.api_key))
    5. app.use(express.static(spaDir)) — static file serving
    6. app.get("*", (_req, res) => { res.sendFile(path.join(spaDir, "index.html")); }) — SPA fallback
    Return app.

    Export async function startServer(credentials: Credentials, opts: ServerOptions = {}): Promise<ServerHandle>:
    1. const port = await getPort({ port: opts.port ?? DEFAULT_PORT })
    2. const spaDir = getSpaDir(opts.spaDir)
    3. const app = buildApp(credentials, port, spaDir)
    4. const httpServer = createServer(app)
    5. await listen(httpServer, port, "127.0.0.1")
    6. const url = `http://127.0.0.1:${port}`
    7. (opts.stdout ?? process.stdout).write(`Workspace: ${url}\n`)
    8. await (opts.openBrowser ?? ((u: string) => open(u)))(url).catch(() => undefined)
    9. const close = (): Promise<void> => new Promise((resolve) => { httpServer.closeAllConnections(); httpServer.close(() => resolve()); })
    10. return { port, close }

    Helper: listen() wraps server.listen in a Promise (resolve on listen, reject on error event).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → CLI Express server | Origin-locking (Host guard + CORS) prevents cross-origin browser tabs from reaching the server |
| CLI Express server → bragfast backend | Bearer token injected server-side in proxyReq; never returned in any response |
| Network → CLI TCP socket | Bound to 127.0.0.1 — unreachable from LAN or internet |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Spoofing (DNS rebinding) | server.ts hostGuard middleware | mitigate | Host header checked before CORS; requests with Host ≠ `127.0.0.1:<PORT>` receive 401 immediately. Verified by origin-lock.test.ts wrong-Host test. |
| T-03-05 | Spoofing (cross-origin tab) | server.ts corsMiddleware | mitigate | cors() dynamic origin callback rejects any Origin ≠ `http://127.0.0.1:<PORT>`; returns 403 at preflight. Verified by origin-lock.test.ts wrong-Origin test. |
| T-03-06 | Information Disclosure (Bearer leak) | proxy.ts createBackendProxy | mitigate | setHeader called on proxyReq (outbound to backend); Authorization is NOT set on the inbound response. Verified by proxy.test.ts response-header assertion. |
| T-03-07 | Elevation of Privilege (network exposure) | server.ts server.listen() | mitigate | Bind address is hardcoded to "127.0.0.1" — verified by grep gate in acceptance criteria. |
| T-03-SC | Tampering | express, cors, get-port, http-proxy-middleware installs | mitigate | All packages [ASSUMED] slopcheck; Plan 03-05 blocking human checkpoint gates npm install before execution. |
</threat_model>
