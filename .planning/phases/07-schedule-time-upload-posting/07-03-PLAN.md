For each format, call `createPresignedUploadUrl(key, "image/jpeg", 300)` where key is deterministic and scoped: `scheduled/${auth.userId}/${draftId}/${format}.jpg`. Return `{ uploads:[{ format, key, uploadUrl, publicUrl }] }`.
  </action>

  <action>
    Implement `POST /api/v1/schedule`. Authenticate with `authenticate(request)`. Validate body:
    - `draftId` non-empty and not unsafe
    - `urls` and `keys` are records keyed by image formats only
    - `selections` is non-empty and every entry has `format:"landscape"|"square"|"portrait"`, `provider:"buffer"`, non-empty `channelId`, optional `channelName`
    - `caption` is a string
    - `scheduling.type` is `"queue"` or `"custom"`; custom requires valid ISO `scheduledAt`
    Call `convex.action(api.schedulePush.run, { userId: auth.userId, ...validated })`. Return 200 on `{ok:true}` and map known false errors to actionable status codes: `upload_missing` → 409, `buffer_not_connected` → 400, auth/channel/provider failures → 502.
  </action>
  <acceptance_criteria>
    - `src/app/api/v1/schedule/route.ts` calls `api.schedulePush.run`
    - `grep "video" src/app/api/v1/schedule/route.ts` shows video formats are rejected or absent from allowed formats
