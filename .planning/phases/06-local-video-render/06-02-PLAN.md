Clip duration probe (D-07 loop — RESEARCH.md Q6 RESOLVED):
The CLI resolver calls probeClipDurationInFrames(absoluteVideoUrl) before building inputProps.
- absoluteVideoUrl is the already-rewritten http://127.0.0.1:<port>/media/<filename> URL.
- probeClipDurationInFrames fetches the leading bytes (Range: bytes=0-4MB), walks the MP4 box structure to find moov > mvhd, returns Math.round(durationSeconds * 30).
- Returns null on failure (non-faststart, non-MP4, network error) — fall back to 240 (treat as trim case).
- If clipDurationInFrames < 240: pass videoDurationInFrames = clipDurationInFrames → composition loops.
- If clipDurationInFrames >= 240: pass videoDurationInFrames = 240 → OffthreadVideo trims at frame 240.
- Short clip loop is enforced in the Remotion composition (VideoCanvasComposition.tsx) via <Loop durationInFrames={videoDurationInFrames}> wrapping OffthreadVideo when the object has a videoUrl. The resolver passes videoDurationInFrames through inputProps; the composition reads it.

probeClipDurationInFrames implementation (copy + adapt from src/lib/video/probe.ts):

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → POST /api/local/render/video | Untrusted body: draftId, format. Both must be validated before use. |
| HTTP client → GET /api/local/render/video/:id/status | req.params.id used as Map key and in path construction — path traversal risk. |
| CLI process → @remotion/renderer (headless Chrome) | Remotion starts a subprocess; inputProps must be JSON-serializable (Pitfall 4 in RESEARCH.md). |
| CLI server → /media static route | Serves files from ~/.brag/media; headless Chrome fetches via absolute localhost URL. |
| probeClipDurationInFrames → /media static route | Probe fetch hits the CLI's own /media route; localhost only, no auth risk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01-CLI | Spoofing | POST /api/local/render/video origin | mitigate | Inherits originLockMiddleware (hostGuard + CORS) already applied in buildApp — no per-route change needed |
| T-06-02-CLI | Tampering | req.params.id in status route | mitigate | isUnsafeOutputId(id) guard rejects ".." and "/" before Map lookup (mirrors image status route pattern) |
