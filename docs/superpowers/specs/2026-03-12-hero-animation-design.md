# Hero Animation: Animated API Sequence

## Overview

Replace the right-side video placeholder in the landing hero with an auto-looping animated sequence that shows a `curl` request typing out, receiving a 202 → webhook 200, then fanning out 3 output images. Pure CSS animations, pre-rendered demo images, no API calls.

## Animation Sequence

| Phase | Duration | What happens |
|-------|----------|-------------|
| 1. Type request | ~2.5s | `curl -X POST ...` types out character by character |
| 2. 202 Accepted | ~0.8s | Response fades in: `{ release_id: "rel_a1b2c3", status: "processing" }` |
| 3. Processing | ~1.5s | Pulsing dots: `Generating images...` |
| 4. 200 OK webhook | ~0.5s | `← 200 OK (webhook)` + `{ status: "complete", images: [3] }` |
| 5. Images fan out | ~1.0s | 3 images cascade in with staggered delays |
| 6. Hold | ~3.0s | Final state visible |
| 7. Reset | ~0.3s | Fade out, restart loop |

**Total loop: ~9.6s**

## Component Structure

```
<HeroAnimation />  — single React client component ("use client")
├── Terminal chrome wrapper (dark bg, dot controls, "terminal" label)
├── Code lines (curl command, 202 response, processing, 200 response)
│   └── Each line has a CSS animation-delay matching the timeline
└── Image fan (3 <Image> elements, absolutely positioned)
    ├── Landscape (-6° rotation, left)
    ├── Square (0° rotation, center)
    └── Portrait (+6° rotation, right)
```

**File:** `src/components/landing/hero-animation.tsx`

## Terminal Chrome

- Dark background (`#1a1a2e` or similar dark tone)
- Wrapped in site's pixel-art border: `border-2 border-brand shadow-[6px_6px_0_var(--color-brand)]`
- Title bar with square dot controls in brand colors (gold, surface/30, surface/30)
- Label: "terminal" in monospace

## Code Content

Simplified curl to fit the space:

```
curl -X POST bragfast.com/api/v1/release \
  -d '{ "title": "Dark mode is here", ... }'

← 202 Accepted  { release_id: "rel_a1b2c3" }

Generating images...

← 200 OK (webhook)  3 images ready
```

- Font: `var(--font-geist-mono)`
- Syntax coloring: command orange, strings green, status codes gold/green
- Typing effect via CSS `steps()` on `width` + `overflow: hidden` on a `<span>`

## Image Fan

- Uses real demo images: `standard-browser-inter-landscape.jpg`, `-square.jpg`, `-portrait.jpg`
- Next.js `<Image>` with explicit width/height, `priority={false}`
- Positioned absolutely within a relative container below the terminal
- Layout:
  - Landscape: left-aligned, `rotate(-6deg)`, z-index 1
  - Square: centered, no rotation, z-index 2
  - Portrait: right-aligned, `rotate(6deg)`, z-index 3
- Entrance: `translateY(20px) + opacity: 0` → `translateY(0) + opacity: 1`, staggered 150ms apart
- Border: `2px solid brand`, `shadow-[3px_3px_0_var(--color-brand)]`

## Animation Approach

**CSS keyframes only.** No framer-motion, no JS animation libraries.

- Master animation on the container: `animation: hero-loop 9.6s infinite`
- Each child element uses `animation-delay` relative to the loop start
- Typing uses `@keyframes type { from { width: 0 } to { width: 100% } }` with `steps(N)` where N = character count
- Fade-ins use `@keyframes fadeIn { from { opacity: 0 } to { opacity: 1 } }`
- Image entrance uses `@keyframes slideUp { from { opacity: 0; transform: translateY(20px) rotate(Xdeg) } to { opacity: 1; transform: translateY(0) rotate(Xdeg) } }`
- Reset: all elements return to `opacity: 0` at the end of the loop via `animation-fill-mode: both` and a reset keyframe

- Responsive: on mobile (`md:` breakpoint), the animation stacks below the text. Scale down image fan proportionally.

## Responsive Behavior

- **Desktop (md+):** Full animation with fanned images at comfortable size
- **Mobile:** Terminal block scales down. Image fan uses smaller dimensions. Consider hiding the image fan on very small screens (`sm:hidden`) and showing only the terminal sequence if space is too tight.

## Accessibility

- `prefers-reduced-motion: reduce` → show the final resting state (code + images) statically, no animation
- Terminal block gets `aria-hidden="true"` (decorative)
- Alt text on images: "Example landscape/square/portrait social image generated by bragfast"

## Performance

- Demo images already exist in `/public/demo/`, served statically
- No JS animation runtime — CSS only
- `"use client"` needed only for the component (not the whole page)
- Images lazy-loaded (below fold on mobile, visible on desktop but not LCP)

## Out of Scope

- Cycling through different template/font combos per loop (future enhancement)
- Interactive elements (clicking, hovering to pause)
- Real API calls
