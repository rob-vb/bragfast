## Expanded Description (for the long bio / full pitch — not the 500-char field)

Developers ship features but never make social content to announce them. brag.fast fixes that.

**One API call or GitHub release → branded social images and video in every format.**

Here's how it works:
- **Kitchen:** Open the admin, pick a template, fill in your release details, click Cook — images and video in seconds. No code required.
- **API:** POST your release data to `/api/v1/cook` — get landscape, square, and portrait images back. Add `"video": true` for MP4.
- **GitHub App:** Publish a release → images and video auto-generate. Review or auto-approve.
- **AI Skill:** Install the MCP server in Claude Code → "make me release images for v2.1" just works.

AI reads your changelog, picks the highlights, renders branded visuals with your colors, logo, and fonts. Video uses the same branded slides with animated transitions at 30fps.

**What you get:**
- Multi-format output (landscape, square, portrait) in one call
- Custom templates with a visual canvas editor
- Brand kits (colors, logos, Google Fonts)
- Per-object video animations (fade, slide, bounce, Ken Burns)
- Webhook delivery + CDN hosting

**Pricing:** 10 free credits, no card required. Paid plans start at $29/mo.

Stop letting releases go unannounced. Show what you've been cooking.
